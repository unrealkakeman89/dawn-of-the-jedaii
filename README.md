# Dawn of the Je'daii

GM campaign guide for a Foundry VTT + SW5e campaign set in **36,453 BBY (0 TYA)**—the Tho Yor Arrival and founding of the Je'daii Order.

## Quick start

1. Session 0: run boon visions from **Chapter 17**.
2. Read **Chapter 16** (Scene Cards), **Chapter 04**, and **Chapter 10** for Session 1.
3. Import the Foundry journal (see `foundry/README.md`).
4. Share only **Appendix C** with players before Session 1 (plus boon visions, not GM effects).
