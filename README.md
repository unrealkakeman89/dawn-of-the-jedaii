## Quick start

1. **Feel the campaign:** skim the [Living Force GM book](gm-narrative/dawn-of-the-jedaii-living-force-gm-book.md) (especially Tho Yor + Session 0).
2. Session 0: character creation from **Campaign Guide Chapter 10** (planet + Force + calling), boon visions from **Chapter 11**, checklist in **Chapter 13**.
3. Read **Chapter 21** (Scene Cards), **Chapter 04**, and **Chapter 15** for Session 1 (Episode 1 checklist: Ch 13).
4. Import the Foundry journal (see `foundry/README.md`).
5. For print/PDF of the *reference* guide: open `gmbinder/dawn-of-the-jedaii-gmbinder.md`, copy all, paste into a new [GM Binder](https://www.gmbinder.com) document.
6. Share **Appendix C** (+ Ch 10 chargen lists if helpful) with players before Session 1 (plus boon visions, not GM effects).
