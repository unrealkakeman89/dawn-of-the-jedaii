## Quick start

1. Session 0: character creation from **Chapter 08** (planet + Force requirement) and boon visions from **Chapter 17**.
2. Read **Chapter 16** (Scene Cards), **Chapter 04**, and **Chapter 10** for Session 1.
3. Import the Foundry journal (see `foundry/README.md`).
4. For print/PDF: open `gmbinder/dawn-of-the-jedaii-gmbinder.md`, copy all, paste into a new [GM Binder](https://www.gmbinder.com) document.
5. Share **Appendix C** (+ Ch 08 chargen lists if helpful) with players before Session 1 (plus boon visions, not GM effects).
