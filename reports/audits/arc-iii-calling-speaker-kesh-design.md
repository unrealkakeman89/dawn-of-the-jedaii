## 2. Models A / B / C — definitions and comparison

Source definitions: Arc III plan §9.1a; decision-record Addendum 2026-08-27 §8.

| Model | Description | When to use |
|-------|-------------|-------------|
| **A — Fixed triple** | Each Calling locks permanently to one Speaker and one destined Kesh | Only when strong **primary-guide** evidence supports a fixed campaign relationship **and** Kakeman89 later elevates that cell to fixed canon |
| **B — Recommended casting** | Default Calling → Speaker → Kesh recommendation; GM may substitute unless later fixed | **Kakeman89 preferred direction** for the crosswalk as a whole |
| **C — Independent systems** | Calling, Speaker contact casting, and Kesh destiny loosely coupled; no forced 1:1 | Prefer for **specific Speakers/Callings** when repository evidence is insufficient for A or B |

### Comparison table

| Criterion | Model A (Fixed triple) | Model B (Recommended casting) | Model C (Independent systems) |
|-----------|------------------------|-------------------------------|-------------------------------|
| **Clarity for GM** | Highest once locked; brittle if wrong | High: default + substitution note | Lower for Session 0 ship flavor; highest for free casting |
| **Source support needed** | Strong continuous primary evidence | Moderate primary + optional companion texture | Thin or conflicting evidence |
| **Flexibility at table** | Low | Medium–high | Highest |
| **Arc III usability** | Risky if party calling ≠ best contact Speaker | Strong: cast by recommendation; swap for scenario | Strong for scenario casting; weak for “sister ship of our calling” |
| **Kesh continuity** | Perfect lock Calling↔Speaker↔Kesh | Calling↔Kesh stays fixed (Ch10); Speaker recommended | Calling↔Kesh fixed; Speaker unrelated |
| **GM substitution** | Discouraged / forbidden if fixed | Explicitly allowed (F-H-001 direction) | Always |
| **Unsupported-canon risk** | Highest if forced 1:1 without evidence | Medium if recommendations overclaim | Lowest for mappings; risk of under-using ship theme |
| **Maintenance** | High (every Speaker rewrite = canon ripple) | Medium | Low for crosswalk; higher for scenario notes |

**Working posture for this report:** Prefer **Model B** overall; allow **Model C** (or relationship class *independent of Calling* / *insufficient evidence*) per Speaker when evidence is thin. Do **not** assume eight clean fixed pairings (Model A rejected as default).
